| Class | Part |
| --- | --- |
| `.alert` | Container |
| `.alert-title` | Heading line |
| `.alert-description` | Body copy |
| `.alert-destructive` | Error variant |

## With an icon

An `svg` as the first child shifts the layout into its icon column automatically.

<Preview code={`<div class="alert">
  <svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2">
    <circle cx="12" cy="12" r="10"></circle>
    <path d="M12 16v-4M12 8h.01"></path>
  </svg>
  <h3 class="alert-title">Scheduled maintenance</h3>
  <p class="alert-description">The API is read-only between 02:00 and 03:00 UTC.</p>
</div>`} />

## Title only

<Preview code={`<div class="alert">
  <h3 class="alert-title">Draft saved</h3>
</div>`} />

An alert that appears after page load should be announced. Add `role="alert"` for errors, or
`role="status"` for confirmations, so assistive tech reads it without moving focus.
