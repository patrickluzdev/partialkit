| Class | Part |
| --- | --- |
| `.card` | Container |
| `.card-header` | Title area |
| `.card-title` | Heading |
| `.card-description` | Supporting line |
| `.card-action` | Control pinned to the header's right edge |
| `.card-content` | Body |
| `.card-footer` | Actions row |

## With an action

`.card-action` sits in a second header column, which only appears when the class is present.

<Preview src="card/with-an-action" width="md" />

## As a form

The card is a plain container, so it takes any element — a `<form>` here, so the footer's submit
button posts without extra wiring.

```html
<form class="card" method="post" action="/projects">
  <div class="card-header">
    <h3 class="card-title">New project</h3>
  </div>
  <div class="card-content">…</div>
  <div class="card-footer">
    <button class="btn" type="submit">Create</button>
  </div>
</form>
```
