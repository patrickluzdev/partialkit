This is the platform `<select>`: keyboard behaviour, type-ahead, and the native picker on mobile
all come free, and it submits with a plain form post. Reach for it first — a custom listbox is
worth building only when you need rich option content.

## States

<Preview code={`<div style="display: flex; flex-direction: column; gap: 0.75rem; max-width: 22rem">

  <select class="native-select" aria-invalid="true" aria-label="Invalid example">

</div>`} />

## Multiple

`multiple` grows the control into a list box. Set an explicit height so it does not collapse.

<Preview code={`<select class="native-select" multiple style="max-width: 22rem; height: 8rem" aria-label="Permissions">
  <option>Read</option>
  <option>Write</option>
  <option>Deploy</option>
  <option>Admin</option>
</select>`} />
