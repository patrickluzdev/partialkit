| Class | Use |
| --- | --- |
| `.badge` | Default, filled with the primary colour |
| `.badge-secondary` | Lower emphasis |
| `.badge-destructive` | Errors and danger states |
| `.badge-outline` | Border only |

A badge is decorative markup. When it carries state a user must know about, put that state in text
as well, or give the badge an accessible name.
