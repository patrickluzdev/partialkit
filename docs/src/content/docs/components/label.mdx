<Preview code={`<div class="field" style="max-width: 22rem">
  <label class="label" for="label-name">Full name</label>
  <input class="input" id="label-name" placeholder="Ada Lovelace" />
</div>`} />

Use a real `<label>` with `for` pointing at the control's `id`. That association is what makes the
label clickable and what a screen reader announces — no class can substitute for it.

## Wrapping the control

When there is no `id` to point at, wrap the control instead.

<Preview code={`<label class="label">
  <input type="checkbox" />
  Remember this device
</label>`} />

## With extra content

The label is a flex row, so hints sit inline.

<Preview code={`<div class="field" style="max-width: 22rem">
  <label class="label" for="label-key">
    API key
    <span class="badge badge-outline">Required</span>
  </label>
  <input class="input" id="label-key" placeholder="pk_live_…" />
</div>`} />

A disabled control dims its label automatically when both sit inside a `.field`.
