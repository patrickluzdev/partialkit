## Types

<Preview src="input/types" layout="stack" width="sm" />

## States

<Preview src="input/states" layout="stack" width="sm" />

| State | How |
| --- | --- |
| Error | `aria-invalid="true"` |
| Disabled | the native `disabled` attribute |
| Focus ring | automatic, on `:focus-visible` |

Always pair an input with a [`.label`](/components/label/), or give it an `aria-label` when the
design has no visible label.
