## Types

The class styles a native `<input>`, so every type keeps its own behaviour and mobile keyboard.

  <input class="input" type="file" aria-label="Attachment" />
</div>`} />

## States

<Preview code={`<div style="display: flex; flex-direction: column; gap: 0.75rem; max-width: 22rem">
  <input class="input" value="Read only" readonly aria-label="Read only example" />
  <input class="input" value="Disabled" disabled aria-label="Disabled example" />
  <input class="input" value="Invalid" aria-invalid="true" aria-label="Invalid example" />
</div>`} />

| State | How |
| --- | --- |
| Error | `aria-invalid="true"` |
| Disabled | the native `disabled` attribute |
| Focus ring | automatic, on `:focus-visible` |

Always pair an input with a [`.label`](/components/label/), or give it an `aria-label` when the
design has no visible label.
