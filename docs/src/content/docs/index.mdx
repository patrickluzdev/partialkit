## Why it exists

shadcn/ui gets its behaviour from Radix, which only runs in React. partialkit reaches the same
place from two directions: **browser primitives** where the platform already implements the
pattern, and an **explicit ARIA layer** where it does not.

<Preview src="index/why-it-exists" width="md" />

## What you get

- **Semantic classes** — `class="btn btn-outline"`, not twenty utilities in every template.
- **shadcn tokens** — the same OKLCH variables, so a theme ports straight over.
- **Names you already know** — components, parts and states match shadcn/ui.
- **htmx-safe** — swapped markup mounts itself, with no re-init call.
- **~8 kB of JS**, minified and unzipped.
