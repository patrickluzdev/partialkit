## Why it exists

shadcn/ui gets its behaviour from Radix, which only runs in React. partialkit reaches the same
place from two directions: **browser primitives** where the platform already implements the
pattern, and an **explicit ARIA layer** where it does not.

Nothing about it assumes a framework. A static page, a server-rendered app in any language, a
site generator, a browser extension — anywhere HTML ends up, these classes work.

## What you get

- **Semantic classes** — `class="btn btn-outline"`, not twenty utilities in every file.
- **shadcn tokens and names** — the same OKLCH variables, and the naming you already know.
- **Markup that arrives later just works** — no re-init call after you replace part of the page.
- **~8 kB of JS**, minified and unzipped.
