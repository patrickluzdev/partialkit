Components for HTML you render on the server

shadcn-inspired styling as plain Tailwind classes, plus a small ESM runtime that survives htmx swaps. No React, no Vue, no build step required in your Go project.

Get started GitHub

Install

Drop-in (any Go project)

Copy the two built files into your static directory. Everything is self-contained. 

cp node_modules/partialkit/dist/partialkit.min.css static/
cp node_modules/partialkit/dist/partialkit.min.js  static/
<link rel="stylesheet" href="/static/partialkit.min.css">
<script type="module" src="/static/partialkit.min.js"></script>

With your own Tailwind build

Pull the source so Tailwind utilities and partialkit share one stylesheet.

@import "tailwindcss";
@import "partialkit/css/source";

Accessibility

shadcn/ui gets its behaviour from Radix, which is React-only. partialkit reaches the same place from two directions: browser primitives where the platform already implements the pattern, and an explicit ARIA layer where it does not. Attributes you set yourself are never overwritten.

From the platform

  • Focus trap, Esc and background inert
  • Top layer and light dismiss
  • Focus restored to whatever opened the overlay

From partialkit

  • Menu roles, aria-expanded, aria-controls
  • Arrow keys, Home/End, type-ahead, Tab to close
  • Dialogs labelled by their own title and description
  • data-disabled mirrored to aria-disabled
  • prefers-reduced-motion honoured

Works after an htmx swap

Triggers use event delegation on document, and a MutationObserver mounts anything that needs per-element state. Markup that arrives in a response behaves like markup that shipped with the page.
